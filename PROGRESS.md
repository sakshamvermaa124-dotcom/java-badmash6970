# Core Java OOP Research

Java is an object-oriented programming language where programs are designed using classes and objects. Core Java OOP is based on four major principles: encapsulation, inheritance, polymorphism, and abstraction.

* **Class:** A blueprint that defines the properties and behaviors of objects.
* **Object:** An instance of a class that contains state and behavior.
* **Encapsulation:** Bundling data and methods together and controlling access using access modifiers such as `private`, `public`, and `protected`.
* **Inheritance:** Allows one class to acquire properties and methods from another class using `extends`.
* **Polymorphism:** Allows the same method or interface to behave differently depending on the object. It includes method overloading and method overriding.
* **Abstraction:** Hides implementation details and exposes only the necessary functionality using abstract classes and interfaces.
* **Interface:** Defines a contract that classes can implement using the `implements` keyword.
* **Constructor:** A special method used to initialize objects when they are created.
* **Method Overloading:** Multiple methods with the same name but different parameters.
* **Method Overriding:** A subclass provides its own implementation of a method inherited from its parent class.
